# FirstSymbol Hub

Одно окно редактора для пакетов FirstSymbol ([Lettera](https://github.com/FirstSymbol/lettera-unity), [Vectra](https://github.com/FirstSymbol/vectra-unity)): что установлено и какой версии, что не сочетается, настройки каждого продукта и его карточка состояния, ссылки на документацию и список изменений, и проверка обновлений, которая выключена, пока вы её не включите.

[English version](README.md)

## Установка

Unity Package Manager → **+** → **Add package from git URL...**:

```
https://github.com/FirstSymbol/FSHub.git
```

Нужен Unity 6.3 LTS (6000.3) или новее. Хаб работает только в редакторе и ничего не добавляет в сборку.

## Как пользоваться

**Window > FirstSymbol > Hub** (а также **Tools > FirstSymbol > Hub**).

- **Overview**: установленные продукты с версией, источником (git, локальная папка, реестр), коммитом и ссылками; неустановленные продукты с git-адресом для копирования; список совместимости, если две установленные версии не подходят друг другу.
- **Страница продукта**: карточка состояния, которую заполняет продукт, и его собственная страница Project Settings прямо в окне. Та же страница есть в **Project Settings > FirstSymbol > <Продукт>**.
- **Hub settings**: светлая, тёмная тема или как в редакторе; проверка обновлений; карточка первого запуска.

## Сеть

По умолчанию хаб ничего не отправляет. Переключатель **Check GitHub for new tags once a day** заставляет его раз в сутки, при открытии окна, запрашивать публичный список тегов на GitHub по одному запросу на установленный продукт. **Check now** делает это один раз. **Update** и **Install** сначала спрашивают, затем передают адрес Package Manager. Без входа в аккаунт, без телеметрии.

## Автору продукта

Продукт поставляет маленькую editor-сборку, которая существует, только когда установлен хаб (`versionDefines` на `com.firstsymbol.hub` и этот define в `defineConstraints`), и один класс-наследник `FirstSymbol.Hub.HubProduct` (см. пример в [README.md](README.md)). Хаб находит его по типу. Страница настроек продукта — обычный `[SettingsProvider]` по пути `Project/FirstSymbol/<Имя>`, хаб показывает её у себя. Без хаба продукт собирается и работает как раньше.
